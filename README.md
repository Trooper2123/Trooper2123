Olá! Sou a Tereza, desenvolvedora backend, entusiasta de tecnologia e alguém que acredita que resolver problemas é muito mais interessante do que simplesmente escrever código.

Minha experiência passa por **sistemas financeiros, antifraude, segurança e saúde**, trabalhando com APIs REST, microsserviços e aplicações que precisam continuar funcionando mesmo quando a sexta-feira chega com um deploy inesperado. 🚀
